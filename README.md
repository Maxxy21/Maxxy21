A production web application with 207 free tools for PDFs, images, data and
everyday calculations.

- React 19 and TanStack Start on Cloudflare Workers
- 34 locales with controlled search indexing
- Client-side PDF, image and WebAssembly processing
- More than 1,300 automated tests
- Search, structured data, localized routes, embeds and a public API

Start with the [PDF page organizer](https://monu.tools/en/tools/pdf-organize)

## Selected work

### Amazon operations extension

I replaced a repeated 15-minute manual workflow with a one-click browser
extension used by an operations team. The tool collected delivery-partner
information, prepared the required message and reduced copy-and-paste errors.
The code is internal, so the repository is not public.

### [Pista](https://pista-app.vercel.app)

My bachelor thesis project. Founders record a pitch and receive structured
feedback on the problem, solution, business model and presentation. Built with
TypeScript, Next.js, Convex and the OpenAI API.

### [Tourism data pipeline](https://github.com/Maxxy21/Programming-Project-OpenHub)

A multithreaded Java application that validates and processes tourism data from
external APIs. Built with Java, ExecutorService, REST APIs, Gson, Jackson and
Maven.

### [C compiler](https://github.com/Maxxy21/simple-c-compiler)

A compiler built with C, Flex and Bison, including parsing, symbol tables, type
checking, control flow and line-numbered diagnostics.
